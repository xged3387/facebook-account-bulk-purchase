## 六、买回来怎么上号，才不容易被封

这一段是整个流程里最容易被忽视、但其实最值钱的部分。你花钱买了一批号，结果因为上号姿势不对，三天封一半，那省下来的采购费全打了水漂。下面这几条是行业里反复验证过的"保号守则"，建议你照着做：

### 1. 上号前先清环境

AccountBoy 官方就明确提示：登录前先清浏览器缓存，或者把手机 APP 卸载重装。原因是上一位使用者留下的 cookie 和设备指纹会跟你的当前环境冲突，Facebook 一眼就能看出"这个号的设备突然变了"。

### 2. 一号一 IP，绝对不要共用

这是铁律。同一个 IP 登录多个账号，是 Facebook 风控系统最容易识别的关联模式。一旦其中一个号出问题，同 IP 的其他号大概率会被连坐。批量场景下，每个号都要配一个独立的住宅代理 IP，并且 IP 的地理位置要跟账号本身的注册地区匹配——美国号配美国 IP，英国号配英国 IP，别图省事用机房 IP 或者随便一个 VPN。

### 3. 登录后不要立刻改资料

刚拿到号，最忌讳的就是登录进去马上改头像、改名字、绑邮箱、绑手机。Facebook 会把这种"一夜之间换主人"的行为直接标记为异常。正确的做法是：登录后先像真人一样刷一刷 feed、点几个赞、看几条视频，48 小时之后再开始改资料，改的时候也要分多次、慢慢改。

### 4. 不要频繁切换设备和 IP

号一旦登录成功，就尽量固定在同一个浏览器环境 + 同一个 IP 上用，别今天用电脑、明天用手机、后天换个代理。每次环境切换对 Facebook 来说都是一次"行为异常"信号，频繁切换等于自找麻烦。

### 5. 批量号建议用指纹浏览器隔离管理

如果你买的是 10 个以上的号，强烈建议用指纹浏览器（比如 AdsPower、Multilogin、GoLogin 这类工具）给每个号配一个独立的浏览器 profile，每个 profile 有自己的指纹和 cookie，互不干扰。配合住宅代理，每个号看起来都是"一台独立设备上的真实用户"，关联风险会大幅下降。

### 6. 关于"180 天禁言"这种情况

AccountBoy 在商品说明里特别提了一点：如果首次登录就显示 180 天禁言，这通常是登录设备的环境和 IP 导致的，这种情况不在售后范围内。所以你拿到号之后，第一件事就是确认上号环境是干净的、IP 是匹配的，避免因为环境问题把一个本来好好的号弄成禁言状态。
